# IDOLVERSE — статический лендинг (этап 2)

Современная адаптивная презентационная страница проекта IDOLVERSE на чистых HTML, CSS и JavaScript. React и бэкенд не используются — это соответствует требованиям второго этапа.

## Запуск локально

1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Для более удобной локальной проверки можно запустить простой сервер из этой папки:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Структура

- `index.html` — семантическая разметка лендинга.
- `styles.css` — дизайн, адаптивные брейкпоинты, анимации и состояния.
- `script.js` — мобильное меню, поиск и фильтры демо-каталога, переходы между связанными карточками, переключение макетов и анимации при прокрутке.
- `assets/` — предоставленные макеты проекта, используемые как изображения-превью.

## Что реализовано

- первый экран с ценностным предложением и CTA;
- описание проблем аудитории;
- блок основных возможностей;
- интерактивная демо-секция: поиск и фильтры K-pop / C-pop / J-pop, карточки артистов и переход к связанному объекту на демонстрационных данных;
- интерактивная секция с переключением 4 макетов;
- интерактивный пример AI-модерации: одобрение/отклонение меняет локальный статус, не публикуя данные и не обращаясь к серверу;
- адаптивная навигация и мобильная версия;
- семантические элементы, подписи кнопок, контрастные состояния фокуса/наведения и поддержка `prefers-reduced-motion`.

## Публикация на GitHub Pages

1. Создайте публичный GitHub-репозиторий.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `script.js` и папку `assets`.
3. Откройте **Settings → Pages**.
4. В разделе сборки выберите публикацию из ветки `main`, папка `/ (root)`.
5. Сохраните настройки и дождитесь появления публичной ссылки.

Важно: демо-каталог использует только демонстрационные данные и работает в браузере; это не бэкенд и не готовая бизнес-логика. Такой объём соответствует этапу 2.

Перед сдачей откройте опубликованный сайт и проверьте его на десктопе и телефоне. Google Fonts подключается онлайн; при отсутствии интернета используются системные шрифты.


### Просмотр макетов
В разделе «Визуальная концепция» макеты открываются в прокручиваемом окне: изображение занимает всю ширину рамки, а страницу можно пролистывать внутри окна колесом мыши, сенсорным жестом или клавишами со стрелками.
